# Controle de Almoxarifado

## Descrição

Sistema web para controle de almoxarifado desenvolvido com HTML, CSS e JavaScript.

O projeto utiliza a MockAPI para armazenar os materiais cadastrados, permitindo realizar operações de cadastro, consulta, atualização e exclusão de dados.

## Funcionalidades

* Cadastro de materiais
* Registro da quantidade em estoque
* Listagem automática dos materiais cadastrados
* Integração com MockAPI
* Baixa de estoque de materiais
* Exclusão de materiais
* Validação de retirada de estoque
* Atualização automática da tabela após operações

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* MockAPI

## API Utilizada

MockAPI
Resource: `materials`
